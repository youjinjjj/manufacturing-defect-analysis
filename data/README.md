# 데이터 준비

[KAMP 제조 AI 데이터셋 플랫폼](https://www.kamp-ai.kr/)에서 사출성형 labeled 데이터를 준비합니다.
수업에서 받은 같은 파일이 있다면 `data/labeled_data.csv`에 놓으면 됩니다. 데이터 원본은 재배포하지 않습니다.

이번 실행에 사용한 파일은 7,996행·45열입니다. `PassOrFail`은 `Y`(정상), `N`(불량)입니다.
다른 버전은 행 수와 스키마를 먼저 확인해야 합니다.

노트북에서 다른 경로를 쓰려면 `MANUFACTURING_DATA` 환경변수로 파일을 지정할 수 있습니다.
CLI에서는 `--data` 옵션을 사용합니다.
