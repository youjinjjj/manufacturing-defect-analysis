# 실험 메모

2026-10-28에 `1=불량`으로 라벨을 통일했습니다. 이전 과제의 기본 F1은 정상 기준이어서 불량 검출률로 읽을 수 없었습니다.
`Reason` 등 검사 결과 정보와 식별자는 명시적으로 제외했습니다.

전처리 통계는 전체 데이터에서 미리 계산하지 않고 Pipeline의 학습 fold 안에서 맞춥니다.
범주형 열은 SMOTENC를 거친 뒤 one-hot encoding하므로 범주를 임의의 소수 값으로 보간하지 않습니다.
노트북과 명령행은 같은 `src/analysis.py`를 사용합니다.

전처리 7개, 분류모델 8개의 층화 5-fold 교차검증과 최종 시험 평가를 다시 실행했습니다.
`results/current/`는 수정 후 결과이고, `historical_*`와 기존 `figures/`는 수정 전 출력입니다.
라벨과 입력 정보가 달라 두 결과를 같은 실험의 성능 향상·하락으로 비교하지 않습니다.

시험셋에 불량이 14개뿐이고, 시간·설비를 분리한 외부 검증은 하지 않았습니다. 실제 공정에 적용할 성능으로 해석할 수는 없습니다.

제품마다 정상 공정값이 달라 전체 IQR로 clipping하면 정상값까지 잘릴 수 있었습니다. 제품·설비별로 기준을 계산하고, 20개 미만의 그룹이나 IQR이 0인 변수는 clipping하지 않습니다. 이 수정은 학습 데이터의 분포를 보고 정했으며 시험 성능을 높이기 위해 고른 설정은 아닙니다.
